## Introduction

LightNovelReader (iOS) is an open-source light novel reader written in Swift and SwiftUI, supporting iPhone and iPad. Its UI and interactions are inspired by the Android app [LightNovelReader](https://github.com/dmzz-yyhyy/LightNovelReader).

> ### ❤️ Special Thanks
>
> **This project is deeply inspired and guided by [LightNovelReader](https://github.com/dmzz-yyhyy/LightNovelReader). Without it, this project would not exist.**
> Thanks to [dmzz-yyhyy](https://github.com/dmzz-yyhyy) and all contributors for their outstanding work and open-sourcing.

## Features

- Real book source: online browsing, searching and reading
- Reader: page-curl paging, scroll mode, adjustable font / size / spacing / background, OLED pure-black night mode
- Bookshelf: multiple shelves, favorites and update notifications
- Offline cache: full-book download, read without network
- Export: EPUB / TXT
- Reading stats: time tracking and heatmap
