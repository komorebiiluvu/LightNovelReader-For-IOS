## Введение

LightNovelReader (iOS) — это открытая читалка ранобэ, написанная на Swift/SwiftUI (UI) + Kotlin Multiplatform (данные), поддерживающая iPhone и iPad. Интерфейс и взаимодействие созданы по мотивам Android-версии [LightNovelReader](https://github.com/dmzz-yyhyy/LightNovelReader).

> **Этот проект глубоко вдохновлён и направлен проектом [LightNovelReader](https://github.com/dmzz-yyhyy/LightNovelReader). Без него этот проект не существовал бы.**

## Возможности

- Реальный источник: просмотр, поиск и чтение онлайн
- Читалка: постраничный переворот, режим прокрутки, настройки шрифта / размера / интервала / фона, чисто-чёрный OLED-ночной режим
- Книжная полка: несколько полок, избранное и уведомления об обновлениях
- Офлайн-кэш: загрузка всей книги, чтение без сети
- Экспорт: EPUB / TXT
- Статистика чтения: учёт времени и тепловая карта
